v2.4 makes the standalone installers simpler to use, reduces bundled tooling and
strengthens the check/install/recovery workflow. Agent and dashboard packages
are versioned 2.4.0 and retain the v2.3 application improvements.

### Installer workflow

- Connect → Check → Install → Open dashboard, with model, firmware and selected
  software version shown before installation.
- Fixed locked-device reboot validation and detection getting stuck after an
  address change.
- Updates and repairs preserve existing dashboard passwords and PIN settings by
  default. Changes and PIN removal are explicit choices.
- Host SSH/ADB and network prerequisites are checked before device changes.
  A dedicated, protected installer SSH identity replaces dependence on the
  user's personal default key for future maintenance.
- Unlock confirmation appears only after actual backup preparation and integrity
  checks. Close/quit protection covers critical operations; preparation can stop
  at a safe boundary.
- Pending deployment transactions are detected after reopening, with a guided
  recovery action and identity verification before recovery.
- Native offline-folder browsing, an Open dashboard action, keyboard-contained
  dialogs and single-instance handling.

### Smaller and more predictable packages

- Pinned Google ADB 37.0.1, retaining only ADB, required libraries and notices.
  Bundled and cached files are verified against fixed hashes before execution.
- Automatic reuse of verified, content-addressed offline bundles.
- Installer/payload major-minor compatibility checks and a pinned release between
  the successful check and installation.
- Manual builds check out the requested release tag for checks and packaging.

### Downloads and signing

- **Windows x64:** choose the setup EXE. MSI and portable ZIP are alternatives.
  Setup uses per-user installation and obtains WebView2 when needed; portable
  users need WebView2 105+ already installed. OpenSSH Client and a compatible
  modem USB driver are also required.
- **macOS 15+:** choose the Apple Silicon (`aarch64`) or Intel (`x64`) DMG.
  Signature-preserving app ZIPs are also available.
- **Signing:** Windows packages are unsigned. Mac packages are ad-hoc signed and
  are not Apple-notarized. Operating-system warnings may appear. Optional signing
  workflows are provided for future credentialed releases.
- `zte-agent` and `dashboard-dist.tar.gz` contain the device application stack.
- `installer-wireframes.zip` contains publishable, labelled sample-data images.
- `sha256sums.txt` covers all published payload downloads.

### Unlock key

Locked devices still require their router admin password and compatible backup-key
suffix. The key is available in the
[upstream issue #8 discussion](https://github.com/jesther-ai/open-u60-pro/issues/8).
It is not embedded in the installers or copied into this repository.

### Validation and limits

Release checks include Rust and UI workflow tests, package startup checks on both
macOS 15 architectures and Windows, and Windows setup/uninstall checks. Package
startup diagnostics exercise the real WebView and bundled ADB with modem commands
disabled. Wireframes use sample data and are not evidence of hardware deployment.

No v2.4 deployment or reboot of a physical modem was performed for this release.
The previously recorded v2.3 physical validation remains distinct from these
installer checks. Power loss and force termination cannot be prevented; retain
recovery snapshots and review the
[safety guidance](https://github.com/dklasens/MU5250-OpenUI/blob/v2.4/docs/SAFETY.md).
Dashboard/API traffic still uses HTTP on the LAN.

[Installer instructions](https://github.com/dklasens/MU5250-OpenUI/blob/v2.4/installer/README.md)
include platform prerequisites, offline use, credential preservation and recovery.
